# 홈 그래픽과 이전 장면

## 현재 로컬 적용안 — 주제 표지

사용자가 4339 비교 화면의 2번을 선택해 실제 Home에 적용했다. 8개 표지의 제목·요약·독서 메모·코드 일부는 공개 글에서 읽으며 대표 글 선택은 `src/data/home-covers.ts`가 관리한다. 선택한 글이 삭제·초안 전환되면 같은 주제의 공개 글로 대체한다.

Mathematics 표지에는 해당 벡터 글의 기존 `public/media/vector-length-dot-cross/length-normalize.svg`를 사용한다. 표지에 맞춰 크기를 줄여 표시하며 원본은 변경하지 않았다. 게임 장면·파동·소개 문구·새 생성 이미지는 사용하지 않는다. 카테고리 색은 CSS로 지정한다. 실제 소스 적용·로컬 검증을 완료했으며 아직 배포하지 않았다.

## 이전 로컬 수정안 — 미디어 제거

사용자가 파동과 소개 제목을 제거하고 카테고리·글 목록 중심으로 변경하도록 요청했다. 현재 Home은 이미지·캔버스를 사용하지 않는다. 이전 파동 소스는 실제 사이트에서 제거하고 `.verification/home-category-designs-20261029/previous-wave/`에 보관했다. 같은 폴더의 새 다섯 초안에도 미디어를 사용하지 않는다. 아직 배포 전이다.

## 이전 로컬 수정안 — 파동 효과

2026-10-29 후속 요청에서 DCB 중심 홈을 취소하고 간단한 그래픽 효과를 넣었다. `src/components/HomeWave.astro`와 `src/scripts/home-wave.ts`의 파동은 AI가 새로 작성한 독립 WebGL 그래픽이다. 게임 캡처·DCB 셰이더·성능 측정 결과가 아니며 외부 모델·텍스처를 사용하지 않는다. 클릭·키보드 파동과 멈춤·재생을 지원하며, WebGL이 불가능한 경우에는 SVG 선을 표시한다. 로컬 미리보기 상태이며 아직 배포하지 않았다.

선명도 수정에서는 가장자리의 흐림을 제거하고 여러 크기의 잔물결, 수면 반사와 굴절광을 닮은 절차적 무늬를 사용한다. 이 무늬는 시각 효과를 위한 근사이며 실제 유체·광선 시뮬레이션이 아니다. 반사광이 과도하게 번쩍이지 않도록 강도를 낮추고 해상도 비율 상한을 2로 높였다.

## 이전 배포안 — DCB 신단

2026-10-29 사용자가 시네마틱 상단과 밝은 글 영역의 초안을 선택하고 실제 홈 적용을 요청했다.

- 화면: DCB 신단의 폭포와 푸른 안개.
- 원본: `media-inbox/dcb-capture-20261020/02-shrine-wide-take01-last.png`.
- 사이트 소스: `src/assets/home/dcb-shrine.png`. 기존 캡처를 변경 없이 복사했다.
- 이전 표시: Astro가 WebP와 640·1280·1920px 응답형 이미지를 빌드하며 CSS로 화면에 보이는 영역을 잘랐다. 현재 로컬 Home에서는 참조하지 않으며 원본 사본은 보존한다.
- 연결: `/projects/dcb/`.

이 장면은 기존 게임 캡처이며 새 게임 실행·촬영 결과가 아니다. 화면에 포함된 자산의 제작 범위는 기존 DCB 프로젝트 설명을 따른다. 캡처에 등장한 모델·텍스처를 모두 자체 제작했다고 설명하지 않는다. 같은 날 후속 요청으로 홈과 본문 변경의 배포를 승인받았다.
