# 노션 수학 기록의 이전 범위

2026년 10월 18일 사용자의 수학 카테고리 분리 요청에 따라 진행했다. 노션 수학 루트와 게임 수학·Mathf 하위의 26개 페이지를 읽었다. 원본 노션은 수정하지 않았다. 『이득우의 게임수학』 독서 메모와 짧은 강의 메모의 주제를 대조하고 새 설명·예제·실습·풀이를 작성했다. 책의 긴 본문이나 그림은 복제하지 않았다.

## 분류와 주소

`math`를 실제 주제 ID로 추가했다. Home의 주제 카드, 사이드 메뉴, 목록 필터, 메타데이터 검증, CLI 생성기, GitHub 새 글 양식, sitemap에 적용된다. 기존 카테고리별 태그 필터는 수학에서도 같은 규칙으로 작동한다.

기존 5개 글은 `content/articles/math/`로 이동했다. 공개 slug와 작성일은 그대로다. 행렬 글에는 동차 좌표와 물리적인 공간 차원을 구분하는 문단을 보완하고 `updated`를 추가했다.

| 기존 위치 | 유지한 slug |
| --- | --- |
| notes | `vector-length-dot-cross` |
| graphics | `matrix-transform-order` |
| graphics | `local-world-clip-ndc-screen` |
| graphics | `camera-basis-lookat` |
| gameplay | `movement-facing-coordinate-space` |

## 신규 글 10편

학습 글 9편과 읽기 순서 안내 1편을 초안으로 작성한 뒤 검토·실행 검사 후 공개 상태로 전환했다.

## 원문의 오류와 미완성 구간

- 벡터 크기 메모의 `sqrt(16+9)=25`는 길이 5와 길이 제곱 25를 구분한다. 기존 벡터 글에 통합한다.
- 이항연산 자체가 교환·결합·분배법칙을 보장하지 않는다는 점을 보완한다.
- 역원은 집합과 연산에 따라 다르며 곱셈 역원은 0을 제외한다. 사원수는 가환 체로 분류하지 않는다.
- 0 계수를 넣어 영벡터를 얻는 것만으로 독립을 증명할 수 없다. 독립과 전체 공간 생성 조건을 구분한다.
- 기저 변경은 같은 벡터의 좌표 표현 변경일 수 있다. 물체가 실제로 이동했다고 단정하지 않는다.
- 평행이동은 원래 공간에서 아핀변환이다. 동차 성분을 물리적인 추가 공간 축으로 설명하지 않는다.
- Atan2는 사분면 정보를 보존한다. 영 나누기 방지만으로 설명하지 않는다. 영벡터 방향은 정책으로 처리한다.
- 포물선 원문은 피타고라스 메모만 있고 운동식이 없다. 삼각함수 장은 비어 있다. 삼각형 정점 기록도 짧다. 이 부분은 신규 설명임을 공개 글에 표시했다.

## 수치 예제 검증

본문에서 13개 프로그램을 추출해 실행했다. 신규 글 9개는 JavaScript 6개와 C# 3개이며, 이동한 기존 4개는 JavaScript다. Node.js 24.15.0과 .NET SDK 10.0.301을 사용했다. C# 빌드는 경고를 오류로 처리했다.

주요 검사는 mod 5 전체 조합, 함수 왕복·정보 손실, 기저 좌표 441개 왕복, 359개 방향 왕복, 평면과 경계·구 후보, 쿼터니언 73개 각도의 역회전·길이 보존, 삼각형 231개 좌표 복원, float 경계·NaN·무한대, 해석적 운동과 Euler 오차다. 기존 JavaScript는 본문 출력과 대조했다.

벡터 글의 두 C# 블록도 별도로 추출해 실행했다. 본문 출력과 기존 49개 검사, 1,000개 결정적 벡터 쌍의 수치 불변량 검사를 통과했다. 검증 자료는 ignored `.verification/math-migration/`와 `.verification/vector-math-20261017/`에 있으며 원문 전체나 비공개 로그를 공개 파일에 포함하지 않는다.

위 검사는 순수 수치 모델의 검사다. Unity 씬·물리·부모 Transform·Euler 표시·보간·GPU 래스터라이저·실제 화면·성능을 실행한 결과로 확대하지 않는다. 각 글의 미검증 범위를 유지한다.

## 사이트 검증

`npm run verify`에서 테스트 8개, Astro 24개 파일의 진단 0개, 정적 빌드와 82개 HTML의 내부 링크·초안 제외·예전 주소 검사를 통과했다. Mermaid 관련 기존 큰 번들 경고는 남아 있으며 빌드 실패는 아니다.

브라우저에서 Home의 6개 주제 카드, 수학 목록 15편, 수학 글에서 사용하는 태그 25개의 정확한 합집합, 전용 태그 선택과 다른 카테고리로 바꿀 때 해제, 본문 검색을 확인했다. 390px 모바일에서 검색·태그 조합과 새로고침 후 URL 복원을 확인했다. 문서 폭은 375px이며 긴 코드만 내부 스크롤을 사용했다. 긴 쿼터니언 글의 KaTeX 22개 표현에 오류가 없고 수식도 화면에서 확인했다.

GitHub 편집 안내에는 수학 선택지와 15개 실제 math 원본 경로가 반영되며 초안은 제외된다. 새 글 초안 생성은 CLI와 GitHub 양식 생성 helper 양쪽 테스트로 확인했다. GitHub 로그인 후 새 글을 저장하는 외부 쓰기 시험은 수행하지 않았다.
