# 지원용 포트폴리오 전용 페이지 관리

2026년 10월 19일 구현하고 로컬 검토를 거쳐 사용자 요청으로 게시 대상으로 확정했다. 공개 경로는 `https://imjae.github.io/portfolio/krafton-2027/`다. 기존 Home·Pinned·블로그 메뉴·DCB 프로젝트·기능 목록·글 본문과 독립적으로 구성한다. 이번 게시에는 전용 화면·데이터·스타일·영상 처리·검사·관리 문서와 sitemap의 새 경로만 포함한다.

## 로컬에서 확인

저장소에서 `npm run dev -- --port 4321`을 실행하고 터미널에 출력된 주소 뒤에 `/portfolio/krafton-2027/`를 붙인다. 포트가 이미 사용 중이면 기존 서버를 종료하지 말고 출력된 실제 포트를 사용한다.

공개 빌드와 같은 결과는 `npm run verify` 후 `npm run preview -- --port 4322`로 볼 수 있다. preview는 `dist`를 사용하므로 원본 수정 후 다시 빌드해야 한다. 이번 화면은 로컬에서도 공개 글만 참조한다.

프로필의 `contact`는 이메일 주소, `period`는 개발 기간, `team`은 팀 구성이다. 확인한 사실만 채우며 빈 값은 화면에 표시하지 않는다. 전용 페이지 순서는 `clientCases`·`graphicsCases`에서 관리한다. 기존 글 제목·주소는 공개 콘텐츠에서 가져오며 Home 고정 순서와 연결되지 않는다.

핵심 사례가 참조하는 글이 삭제되거나 초안으로 바뀌면 빌드가 실패해 누락을 알린다. 공개 가능한 대체 글을 확인한 뒤 연결을 수정한다. 선택적인 추가 글은 공개 상태일 때만 표시한다.

## 영상을 나중에 추가

현재 영상은 지정하지 않았다. 빈 플레이어나 임시 썸네일도 표시하지 않는다. `project.media`는 프로젝트 소개, 각 `clientCases`·`graphicsCases` 항목의 `media`는 해당 사례에 표시한다. 실제 영상이 준비되면 아래 필드를 추가한다.

```ts
media: {
  url: '확인한 HTTPS 영상 주소',
  title: '실제 장면 제목',
  caption: '촬영일 · 대상 버전 · Editor/Player · 해상도·녹화 fps · 이 구간에서 확인한 동작과 남은 검증',
  startSeconds: 15, // 선택: 영상 전체 시작을 기준으로 한 초
  endSeconds: 45,  // 선택: 시작보다 큰 종료 시각
},
```

위 문자열은 작성 양식이다. 실제 주소·제목·캡션으로 바꾸기 전에는 데이터에 붙이지 않는다. 시간 값도 사용할 장면에 맞춰 정한다. YouTube의 watch·youtu.be·shorts·embed 주소를 지원하며, 정확한 ID를 확인해 `youtube-nocookie.com`으로 삽입한다. 일반 HTTPS 영상 주소는 외부 링크로 표시한다. 자동 재생은 사용하지 않는다. 제목·캡션이 없거나 유효하지 않은 주소는 표시하지 않는다.

대표 영상은 기존 DCB 영상 설정의 주소도 재사용한다. 이 설정만 있으면 상단에 외부 링크를 보여주고, 캡션까지 갖춘 `project.media`를 채우면 프로젝트 영역에 삽입한다. 기존 영상 설정 자체를 이번 페이지 작업으로 변경하지 않는다. 저장된 설정은 빌드 시 읽으므로 변경 후 다시 빌드한다.

영상의 존재가 기능 전체의 실행 검증을 뜻하지 않는다. [촬영 계획](DCB-CAPTURE-PLAN.md)에 따라 실제 구간·버전·환경을 대조하고, 공개할 자료가 확정된 뒤 넣는다. `media-inbox` 원본이나 private 코드·로그·저장 데이터는 배포하지 않는다.

## 확인과 공개

- `npm run verify`로 기존 검사와 영상 주소·구간 처리 검사를 실행한다.
- 전용 화면의 본문·앵커·모바일 너비·키보드·관련 글과 영상 상태를 확인한다.
- 기존 Home·긴 본문·모바일 검색의 동작도 확인한다.
- 사용자 게시 요청에 따라 로컬 검토용 `noindex, nofollow`를 해제하고 sitemap에 새 경로를 등록했다. 기존 Home·메뉴는 유지하며, 포트폴리오 목록(`/portfolio/`)의 **크래프톤 지원용 포트폴리오** 링크 또는 전용 주소로 진입한다. 목록의 DCB 항목과 프로젝트 페이지는 그대로 유지한다.
- 커밋할 파일만 분리한 빌드에서도 검증한다. 기존 로컬 소개·글·계획 변경은 자동으로 포함하지 않는다. main에 push한 뒤 같은 커밋의 Actions 성공과 실제 공개 페이지를 확인해야 게시 완료로 기록한다.
