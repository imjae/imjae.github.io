## 기록 기준

2027 크래프톤 인턴십 지원서의 경력 두 항목과 대외활동 한 항목을 보관한다. 2026년 10월 23일 전달한 지원서 입력 화면 세 장과 텍스트를 기준으로 정리했다.

회사명·역할·기간 등은 입력 화면을 따르고, 경력의 **담당업무와 결과는 별도로 전달한 전체 문구**를 사용했다. 텍스투라의 **본인의 기여와 결과는 세 번째 화면에 표시된 전체 문구**를 옮겼다. 문구를 새로 평가하거나 성과를 추가하지 않고, 입력한 내용의 띄어쓰기와 표현을 유지했다.

## 경력 01 · 넷마블 잼팟

| 항목 | 입력 내용 |
| --- | --- |
| 회사명 | 넷마블 잼팟 |
| 근무 국가·지역 | 대한민국 |
| 부서·팀 | 클라이언트 개발팀 |
| 고용 형태 | 정규직 |
| 직급·직무 | 유니티 클라이언트 개발 |
| 담당 역할 | 소셜카지노 슬롯머신 클라이언트 개발 |
| 근무 시작 | 2022.03 |
| 근무 종료 | 2024.12 |
| 재직 중 선택 | 미선택 |

### 담당업무

- Unity/C# 기반 슬롯 게임 클라이언트 개발 및 유지보수
- 서버 응답 데이터를 연동한 릴·심볼 제어, 프리스핀·리스핀·미니게임·보너스 기능 구현
- Animator 기반 UI·당첨 연출 연결 및 테스트 과정에서 발견된 오류 수정
- Azure DevOps와 Addressables를 활용한 콘텐츠 빌드·배포 파이프라인 구축, Git 태그와 스크립트·리소스 버전 관리

### 결과

- 기획·아트·연출 담당자들과 협업해 다양한 형태의 슬롯머신 게임을 개발했습니다.
- Git 태그로 지정한 버전의 Addressables 번들을 빌드하고, 생성된 아티팩트를 Dev·QA·Stage·Real 환경별 Azure Blob Storage에 배포하는 절차를 직접 구축했습니다. 스크립트와 리소스 버전을 분리해 리소스 버전에 맞는 카탈로그를 로드하도록 구성했습니다.

## 경력 02 · 하이퍼텐션

| 항목 | 입력 내용 |
| --- | --- |
| 회사명 | 하이퍼텐션 |
| 근무 국가·지역 | 대한민국 |
| 부서·팀 | 팀구분없음 |
| 고용 형태 | 정규직 |
| 직급·직무 | 공동창업 |
| 담당 역할 | 개발 |
| 근무 시작 | 2024.12 |
| 근무 종료 | 2026.10 |
| 재직 중 선택 | 미선택 |

### 담당업무

- Unity 6·C#·HDRP 기반 DCB의 기획과 시스템 설계부터 게임플레이, UI, 데이터·리소스 관리, 셰이더·이펙트, 제작 도구와 통합·검증까지 개발 전반을 담당했습니다.
- 기존 3D 모델과 외부 제작 애니메이션을 활용했으며, 코드·셰이더·검증 도구 작성에 AI를 활용하면서 구현 방향 결정과 결과 검토·통합을 맡았습니다.

### 결과

지게 운반과 이동·스태미너 제어, IK 트레버설, 몬스터 행동 패턴과 그룹 전투를 구현했습니다. 공통 파츠 데이터를 중심으로 장비의 2D·3D 조립, 프리뷰, 장착·드랍과 저장·복원을 연결했습니다. 물 캐시 재생과 화염 표현을 구현하고, 밸런스·이펙트 편집 도구와 자동 검사 도구를 제작해 게임 기능부터 콘텐츠 제작·검증 환경까지 구축했습니다.

## 대외활동 01 · 텍스투라 BIC 2026 출품

| 항목 | 입력 내용 |
| --- | --- |
| 유형 | 기타 |
| 유형의 추가 입력 | BIC 2026 출품 |
| 활동·프로젝트명 | 텍스투라 |
| 기관·팀명 | 하이퍼텐션 |
| 활동 시작 | 2026.08 |
| 활동 종료 | 2026.08 |

### 본인의 기여와 결과

주 프로젝트 개발과 별도로, 인디 팀 하이퍼텐션의 서브 프로젝트로 참여한 작업입니다. 매치3 퍼즐과 로그라이크를 결합한 연금술 테마 게임 ‘텍스투라(TEXTURA)’에서 게임플레이 프로그래밍을 맡았고, Unity와 C# 으로 기획에 맞는 게임을 구현했습니다.

DCB와 병행했기 때문에 담당 범위를 특정 시스템 구현과 전시 빌드 안정화로 한정하고, 최대한 AI를 활용하여 개발을 진행 하였습니다.

텍스투라는 펄어비스의 인디게임 후원 프로젝트에 선정되어 2026년 8월 14~16일 부산 벡스코에서 열린 BIC 2026의 펄어비스 부스에서 전시했습니다. 현장에서 시연 관람객 피드백을 얻었고, 3일간 같은 상황에서 인디게임 개발을 해 나가는 다양한 팀들과 게임을 직접 경험, 체험할 수 있어 뜻깊은 시간이 되었습니다.
