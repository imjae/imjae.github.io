## 수학 글을 모아서 읽는 순서

노션의 [수학 영역](https://app.notion.com/p/4ea4f1031431474cb720e5b5a95dcc58)과 그 안의 [게임 수학 독서 기록](https://app.notion.com/p/a251bf4881484e3ab054b49a2babcf03)을 블로그의 수학 카테고리로 정리했다. 이 페이지는 14편의 학습 순서와 원문·보완·검증 범위를 안내한다.

노션의 게임 수학 기록에는 **『이득우의 게임수학』을 읽으며 정리한 내용**이 포함되어 있다. 책의 본문·그림을 옮겨 싣는 대신 주제를 대조하고 설명·표·코드·실습을 새로 구성했다. 짧은 메모와 빈 페이지도 있어 노션에 없던 유도를 이번에 보완한 부분은 각 글에 표시했다. 글 작성과 실행 예제 검사에는 AI를 사용했다.

각 글의 개념을 읽고 실행 예제를 돌린 뒤 실습을 먼저 풀어 본다. 풀이와 다른 답이 나왔다면 좌표계, 단위, 부호, 곱셈 순서와 영값 처리를 차례로 확인한다. 수학적 정답과 구현의 허용 오차를 구분한다.

UI에 적용할 때는 별도 도구 글인 [Unity 화면·월드·UI 좌표](/writing/unity-screen-world-ui-coordinates/)로 이어진다. OpenGL API와 렌더링 상태는 [OpenGL 정점·텍스처 파이프라인](/writing/opengl-vertex-texture-pipeline/)을 함께 볼 수 있다.

## 노션의 어떤 부분을 옮겼는가

| 원문 범위 | 정리한 위치 | 보완한 내용 |
| --- | --- | --- |
| 수의 종류, 연산, 수의 구조 | 1번 | 연산 법칙의 조건, 0의 역원 제외, 사원수와 가환 체 구분 |
| 수직선과 수의 표현 | 2번 | 유리수의 조밀성, 부동소수점·정밀도·오차 비교 |
| 함수·합성·항등·역함수·곱집합 | 3번 | 공역에 따른 전사 여부, 정보 손실, 순서쌍과 좌표축 구분 |
| 벡터 공간·연산·선형 결합·기저 | 4번 | 독립성의 증명 조건, 생성과 차원, 표현 변경과 실제 변환 구분 |
| 벡터의 크기, 내적·외적 메모 | 5번 | 기존 벡터 글에 통합, 3-4-5 길이와 영벡터 예외 |
| Mathf.Atan2 | 6번 | 사분면, 단위, 영벡터, 축과 각도 경계 |
| 이동 변환, 공간 수학, 변환 관련 메모 | 7·9·10번 | 이미 게시한 행렬·좌표·카메라 글을 수학으로 재분류 |
| 벡터 수학 뒤의 쿼터니언 메모 | 8번 | 반각·단위 길이·합성 순서와 실행 예제 |
| 공간 수학의 평면·절두체 개요 | 11번 | 거리 유도, 법선 정규화, 반공간 후보 판정 |
| 짧게 남은 삼각형 정점 메모 | 12번 | 넓이·무게중심 좌표·보간을 신규 설명으로 추가 |
| 제목만 삼각함수인 빈 장 | 6번과 연결 | 원문에 완성된 설명이 없음을 표시하고 새로 작성 |
| 포물선 제목 아래 피타고라스 메모 | 13번 | 원문에 운동식이 없음을 표시하고 시간 기반 유도·예제를 추가 |

노션의 수식 예약어 그림은 학습 주제 본문이 아니어서 별도 글로 복제하지 않았다. 책의 구성이나 게임 엔진 구성 같은 목차 메모도 그 자체를 완료한 구현 사례로 옮기지 않았다.

## 기존 글과 주소

기존에 여러 분류에 있던 벡터, 행렬, 좌표 변환 단계, 카메라 기저, 이동 방향 글 5편은 수학 카테고리로 모았다. 각 글의 공개 주소와 작성일을 유지했다. 본문을 중복해서 새 글로 만들지 않았다.

노션 전체에서 옮긴 다른 주제는 [기존 37편 읽기 순서](/writing/notion-study-reading-order/)에 남아 있다. 그 목록 안의 수학 글도 동일한 주소로 연결된다. 수학 카테고리에서는 해당 분류에서 사용한 태그만 보여 주므로 `Vector`, `Transform`, `C#` 등의 태그로 범위를 좁힐 수 있다.

## 실행 예제가 보장하는 범위

순수 수치 예제는 Node.js 또는 .NET 콘솔에서 실행해 계산과 경계 조건을 확인했다. 이는 해당 입력과 모델에 대한 검사다. 유한한 입력 검사로 모든 실수의 수학 명제를 증명한 것으로 읽지 않는다. mod 5 예제처럼 유한 집합 전체를 순회한 경우는 따로 설명한다.

Unity 씬·물리·부모 Transform·애니메이션, GPU 셰이더·실제 화면·성능은 각 글의 미검증 항목에 남겨 두었다. 학습용 좌표 규약과 수치 임계값을 실제 프로젝트에 적용할 때는 입력 범위와 엔진 규약을 확인해야 한다. 실행하지 않은 실습은 실제 측정이나 캡처로 제시하지 않는다.
