## 이동 속도와 조작 가능한 상태를 함께 봅니다

<div id="이동-속도와-조작-가능한-상태를-함께-본다" aria-hidden="true" style="scroll-margin-top: 90px;"></div>

DCB에서는 지게를 진 상태와 내려놓은 상태에 따라 이동과 스태미너 규칙이 달라집니다. 지게를 진 동안에는 기본 걷기와 버튼을 누른 동안의 달리기를 사용하고, 스태미너가 고갈되면 허용되는 걸음으로 내려갑니다. 회복됐더라도 달리기 버튼을 계속 쥐고 있었다는 이유만으로 바로 가속하지 않도록 입력 유지 상태도 정리합니다.

속도 숫자 하나를 바꾸면 이동 거리뿐 아니라 소모하는 자원과 다시 행동할 수 있는 시점에도 영향을 줍니다. 이 묶음에서는 **이동 속도, 이동·행동 비용, 회복 시점, 행동 허용 조건과 입력 제어**를 연결해 설명합니다.

현재 출발점은 [지게 운반의 이동 속도와 스태미너 계산 구조](/writing/jige-carry-burden/)입니다.

이 값을 한 화면에서 편집하고 예상·실측 결과를 비교하는 도구 제작은 [플레이어 밸런싱 도구](/writing/player-balance-tuning-tool/)에서 이어서 설명합니다.

착용 상태에 따른 걸음 선택과 고갈 후 입력 해제·재진입은 [걷기·달리기·질주 전환과 재입력 제어](/writing/locomotion-stamina-reinput/)에서 설명합니다.

[공격·구르기·패리의 비용과 회복](/writing/action-stamina-cost-and-recovery/)에서는 무기·착용별 차감과 회복 타이머를 추적했습니다. 패리는 공격·구르기와 다른 호출 경로여서, 종료 후 회복 규칙이 같다고 설명하지 않습니다.

## 지금 연결된 규칙과 설정

| 축 | 기존 분석에서 확인한 내용 | 설명할 때 구분할 점 |
| --- | --- | --- |
| 상태 | 맨몸과 지게 착용의 이동·소모·회복 규칙 | 빈 지게의 부담과 추가 적재의 부담 |
| 적재율 | 무게를 용량으로 나눈 비율로 배율 계산 | 계산 경로와 실제 저장된 곡선 |
| 이동·행동 비용 | 걸음별 초당 소모와 행동별 비용 적용 | 지속 소모와 한 번 차감하는 비용 |
| 회복 | 소모 중 중단, 종료 후 지연과 행동별 재개 경로 | 회복 수치와 회복 시작 조건 |
| 배고픔·갈증 | 단계별 회복 시간·운반 한도·이동·체력 보정 | 절대 문턱, 실제 저장 배율과 중립인 능력치 보정 |
| 입력 | 고갈 시 걸음 전환과 달리기 입력 유지 해제 | 버튼 상태와 실제 선택한 이동 상태 |

기존 조사에서 적재 속도·소모·회복 곡선은 모두 배율 1이었습니다. 지게 착용 여부에 따른 차이는 있지만, 적재량이 늘 때 곡선으로 추가 감속·소모·회복 변화를 주는 설정은 중립 상태입니다. 코드에 곡선이 있다는 이유만으로 무거운 짐을 실을수록 반드시 느려지는 현재 플레이를 구현했다고 설명하지 않습니다.

이동 속도 보정은 기존 스탯 보정 체계에 연결되어 있습니다. [무게·갈증·물속 감속의 중첩](/writing/movement-speed-modifier-stacking/)에서 무게 곡선·발동 조건·물 배율의 평활과 해제, 최종 스탯 속도가 이동 컨트롤러로 이어지는 경로를 설명합니다.

## 배고픔·갈증의 현재 보정값

문턱은 최대치의 비율이 아닌 현재 자원의 절대값입니다. 다음은 실행 측정값이 아닌 현재 저장 규칙입니다.

| 조건 | 배고픔 | 갈증 |
| --- | --- | --- |
| 현재 수치 25 이하 | 스태미너 회복 시간 ×2.1 | 스태미너 회복 시간 ×2.1 |
| 현재 수치 10 이하 | 위 효과 유지 + 플레이어 운반 한도 ×0.7 | 위 효과 유지 + 이동 속도 보정 ×0.8 |
| 현재 수치 0 | 위 효과 유지 + 체력 2/초 감소 | 위 효과 유지 + 체력 2/초 감소 |
| 단계별 기본 능력치 보정 | 1·2단계 모두 0 | 1·2단계 모두 0 |

두 자원이 모두 25 이하이면 회복 시간은 ×4.41이고, 다른 조건이 같을 때 초당 회복량은 정상의 약 22.7%다. 행동 차감 비용이나 회복 시작 지연을 직접 늘리는 설정과 구분합니다. 로비에서는 자연 감소·체력 피해를 막지만 낮은 자원에 따른 보정은 유지합니다.

감소 속도·질주와 과적의 합산, 지게 회복 배율과의 중첩, 적용·해제 조건은 [행동 비용과 회복 글의 배고픔·갈증 설명](/writing/action-stamina-cost-and-recovery/)에서 이어집니다. 현재 능력치 보정과 근성 완화의 저장값은 0입니다.

## 짐과 다리의 흔들림은 물리 표현에서 다룹니다

<div id="짐과-다리의-흔들림은-물리-표현에서-다룬다" aria-hidden="true" style="scroll-margin-top: 90px;"></div>

[지게 짐의 출렁임](/writing/jige-cargo-secondary-motion/)은 가속도·적재율을 기울기·튐에 연결하고, [밧줄 다리의 물리 흔들림](/writing/rope-bridge-physical-sway/)은 하중·발 접지·바람을 표면 운동에 연결합니다. 해당 피벗·메시·충돌면 구조는 각 기능에서 읽을 수 있습니다.

밸런싱 분석에서는 그 움직임이 이동·자원·입력 제어와 만나는 조건을 다룹니다. 짐이 더 크게 흔들리는 표현과 실제 이동 감속, 다리 표면에 실린 이동과 플레이어가 스스로 걷는 속도를 같은 수치로 취급하지 않습니다. 이 구분을 유지하며 관련 글을 연결합니다.
